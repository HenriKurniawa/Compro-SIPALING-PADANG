# Contributing Guide

## Sebelum coding
Pastikan Issue punya tujuan, scope, kriteria penerimaan, dan status konfirmasi. Jika ada ketidakjelasan yang mengubah alur bisnis, tanyakan dahulu.

## Branch
Buat branch dari `develop` dengan prefix `feature/`, `fix/`, `docs/`, `test/`, atau `chore/`.

## Commit message
- `feat: add cart data endpoint`
- `fix: validate stock quantity`
- `docs: update API contract`
- `test: add inventory validation tests`
- `chore: configure project tooling`

## Pull Request
- PR diarahkan ke `develop`.
- Tautkan Issue dengan `Closes #<number>`.
- Isi template PR dan minta review.
- Jangan merge jika test yang relevan gagal.
