# API Contract

Status: belum ada kontrak API final.

Sebelum integrasi:
1. Sepakati format URL, versi API, JSON, dan format error.
2. Definisikan endpoint, role, validasi, serta contoh request/response.
3. Tandai endpoint yang bergantung pada fitur belum dikonfirmasi.
4. Pastikan frontend dan backend menggunakan nama field dan aturan yang sama.

Untuk setiap endpoint, dokumentasikan: method/path, tujuan, role, request schema, response sukses/error, validasi, dan status Draft / Disepakati / Diimplementasikan / Diuji.
